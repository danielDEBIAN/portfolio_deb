# Daniel Espinoza (@danielDEBIAN) — Portfolio

Portafolio personal minimalista de **Daniel Espinoza Bautista** (`@danielDEBIAN`), Software Engineer en **Ellucian**.

## Características

- **Diseño minimalista sin gradientes**: Paleta monocromática de colores sólidos (`#0a0a0a` en modo oscuro y `#fafafa` en modo claro), bordes de `1px` y tipografía limpia (`Inter` + `JetBrains Mono`).
- **Repositorios pineados de GitHub**:
  - `hytale-tiktok-rcon` — Hytale × TikTok Live Studio (`v2.0.0`, Node.js, Electron, Java 25, RCON)
  - `minecraft-tiktok-rcon` — Minecraft × TikTok Live Studio (`v2.1.0`, Node.js, Electron, RCON Nativo)
  - `ia-clip-editor` — Pipeline de edición de video con IA local (`Python`, `Faster-Whisper`, `Ollama`, `FFmpeg`)
  - `cypher_DES_python` — Cifrador criptográfico DES para imágenes BMP (`Python`, `PyCryptodome`, `Tkinter`)
  - `portfolio_deb` — Portafolio personal minimalista (`Next.js`, `TypeScript`, `Tailwind CSS`)
  - `mylittleflower` — Aplicación web interactiva en `React` y `Firebase`
- **Bilingüe y adaptable**: Selector instantáneo de idioma (`ES` / `EN`) y selector de tema (`Oscuro` / `Claro`).

## Ejecución local

```bash
npm install
npm run dev
```

Abre `http://localhost:3000` en tu navegador.
